# 基于强化学习的公共政策多跳问答 RAG 系统优化研究

2025.05 - 2025.07

- **S｜项目背景**：针对英国公共政策咨询中年龄、收入、家庭关系、居住地及时间等约束密集，用户表达与政策条款结构不一致，直接检索易遗漏前置条件、召回相似但不适用条款的问题，定位 RAG 链路瓶颈为 Query Planner 的约束保真与多跳规划能力。
- **T｜项目目标**：基于 Qwen3-4B-Instruct-2507 构建可生成结构化 JSON 查询计划的 Planner，将上下文相关问题改写为独立检索 Query，并将复杂政策问题拆解为 2～4 跳、带依赖关系的查询 DAG；重点对比 DPO 与 GRPO 两种训练方案对约束保真、检索召回和端到端问答效果的影响。
- **A｜数据工程**：整合 ConditionalQA、QReCC 与 MuSiQue，构建 12,552 个英国政策知识块及 117,528 条多跳辅助语料；构建 20,000 条单跳基础 SFT 与 2,000 条分层多跳 SFT（2/3/4-hop 为 1,000/600/400），并制作 5,000 组 DPO 偏好对（单跳/多跳各 2,500、十类困难负样本各 500）及 5,000 条 GRPO-ready 数据（3,000 条通用多跳、1,000 条证据校验的政策多跳、1,000 条政策单跳），对 MuSiQue 多跳 SFT、DPO、GRPO 做来源 ID 与问题指纹双重隔离。
- **A｜训练方案**：设计“单跳基础 SFT → 多跳 SFT 冷启动 → 共享检查点 → DPO/GRPO”训练路径；DPO 同时强化单跳约束保真与多跳依赖，GRPO 对每个候选计划执行检索与回答完整链路，以 10% 格式塑形、子答案过程分和最终答案语义否决构造奖励，并通过预期跳数、冗余与泄漏门控抑制奖励投机，两条分支从同一冷启动权重出发以控制变量。
- **A｜系统评测**：设计 BGE-M3 + FAISS 检索与答案生成链路，在 ConditionalQA Dev、QReCC Test 和 MuSiQue Dev 上统一评测基础 SFT、冷启动、DPO、GRPO 四个检查点，并按 2/3/4-hop、约束类型及负样本错误类型开展消融分析。
- **R｜项目结果**: DPO 将**单跳 Gold-document Recall@5 由 78.9% 提升至 83.6%**、**Evidence Recall@5 由 68.2% 提升至 74.9%**；GRPO 将**多跳 Joint Recall@5 由 50.1% 提升至 64.5%**、**答案 F1 由 60.5% 提升至 68.7%**，**Planner JSON 合法率保持 99.8%**。
